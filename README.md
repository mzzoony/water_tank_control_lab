# water_tank_control_lab
Industrial automation portfolio project using Ignition SCADA, PLC control logic, alarms, historian, and process simulation.
## Current Progress
- Created simulated Tank_Level and Pump_Running tags in Ignition.
- Built the initial Perspective HMI using a Cylindrical Tank component.
- Bound Tank_Level to the tank visualization for live level updates.
- Added RUNNING/STOPPED pump status using a Boolean tag and an expression transform.
